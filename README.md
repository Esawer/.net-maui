# README - Dziennik Treningów 💪

## Opis
Aplikacja Dziennik Treningów to narzędzie do śledzenia i zarządzania treningami. 
Umożliwia użytkownikom rejestrowanie swoich sesji treningowych, monitorowanie postępów oraz robienia zdjęć progressu.

## Pola
|Nazwa|Typ|Przykład|
|---|---|---|
|Id|Integer|12|
|Nazwa|String|"Pompka"|
|Data|DateTime|25.04.2026|
|Rekord|Integer|45|

## Rozbudowa
Aplikacja będzie mieć funkcje takie jak:
- Dodawanie nowych ćwiczeń
- Edycja rekordów
- Robienie zdjęć progressu
- Statystyki postępów
